# Software Engineering Lab — Experiment 20

## Title

Create a GitHub Repository and Implement Version Control

## Aim

To create a GitHub repository, edit the README file, and manage project changes using version control.

## Description

This repository demonstrates the basic use of GitHub for storing project files and tracking changes.

## Steps Performed

1. Created a new GitHub repository.
2. Initialized the repository with a README file.
3. Edited the README file.
4. Saved the changes to the repository.

## Result

Successfully created a GitHub repository and updated the README file.
## What I Learned

- Creating a GitHub repository.
- Editing and updating project files.
- Saving changes using commits.
- Using GitHub for version control.
